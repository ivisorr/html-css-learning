<h1> - Этот текст может быть введением к тексту, помещенному далее на странице. В случае если текст достаточно длинный, он может быть разделен на несколькоразделов с подзаголовками. <form> - Использование форм


<form - forma
  id="myTestForm" - ID формы ( параметр для CSS и JS)
  method="post" - get/post метод отправки данных формы. 
    GET - как параметр адресной строки.
    POST - в теле HTTP-запроса вида:
      заголовки                 Content-Type: application/x-www-form-urlencoded
        +                       +
      тело запроса с данными    username=Ivan&email=test@example.com
  action="http://my.local/result.php" - web-адресполучателя данных
>

  <fieldset> </fieldset> - объединяет атрибуты формы в набор (на экране в рамке)
  <legend>"Zagolovok"</legend> - звголовок набора (рамки)

  <label for="comments">Что вы думаете об этом выступлении?</label> - заголовок элемента. 
    Связь через id элемента: for="comments" (Для textarea задан id="comments")
  <textarea - многосмтрочноке поле ввода.
    id="comments" - идентификатор (для обращениея в форме, например для lable)
    name="comment" - Имя параметра (поля)ю Передается при отправке формы (POST). 
      Отправится: comment="Текст введенный пользователем в поле"
    cols="60" - ширина поля на экране (длина строки). В примере заданно через CSS для масштабирования.
    rows="4" - высота в строках.
    placeholder="Введите свой комментарий..." - текст-подсказка доввода.
  >
  </textarea>

  <label> Пожалуйста введите имя: - другой вариант использования lable без for="ID"
	<input id="username" type="text" name="username" /> - полеввода 
  </label>
  
  <input id="depart" type="date" name="depart" required="required" /> - ввод даты
    required="required признак обязательности ввода
  <input type="url" name="sait" value="https://yoursite.org" /> - ввод web-адреса
  <input type="email" name="email" /> - ввод email
